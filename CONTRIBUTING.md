# Contributing

Thank you for contributing to H3ddle.

1. Keep changes independent from private codebases and assets.
2. Add tests for timeline, protocol, generation, and export behavior.
3. Preserve model and media files outside Git.
4. Run `Scripts/ci.sh` before opening a pull request.
5. Record durable architectural changes under `docs/decisions/`.

By contributing, you agree that your contribution is licensed under the project
licence.
